# @product/web

Enterprise Task Tracker - Modern Web Frontend (React + TypeScript).

## Overview
This web application provides:
- **Zero-Trust Multi-Tenant Storage Partitioning**: Completely isolated IndexedDB stores per organization.
- **Autonomous Sentinel AI Agent**: Background daemon monitoring production health and healing defects.
- **Interactive Calendar & Kanban Task Board**: Real-time project and sprint management.
- **Payment Gateway & Merchant Bank Settlement**: Allows administrators to configure receiving bank details and collect $1/user/mo or $10/user/yr subscriptions via card gateways or direct bank wire transfers.

## Getting Started
```bash
# From repository root
npm install

# Run development server
npm run dev --workspace=@product/web
```
